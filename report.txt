## 4. Дефекты

### BUG-01
- R-ID: R05
- Заголовок: Насос включается при humidity=35 (граница)
- Начальное состояние: pump=false, vent=false, fault=false
- Шаги: S08/1
- Ожидание: pump=false (35 не <35, зона удержания, previous=false)
- Факт: pump=true, used=2
- Серьёзность: средняя (нарушение гистерезиса, лишние включения)
- Причина: `pumpStart: humidity => humidity <= 35`
- Исправление: `pumpStart: humidity => humidity < 35`
- Регрессия: S01, S06

### BUG-02
- R-ID: R03
- Заголовок: Fault не удерживается при reset=false и age<=30
- Шаги: S12/1 (age=31 → fault=true), S12/2 (age=0, reset=false)
- Ожидание: fault=true, used=0
- Факт: fault=false
- Серьёзность: высокая (работа в аварии без сброса)
- Причина: `hold: (prev, input) => prev.fault && !input.reset && input.age > 30`
- Исправление: убрать `&& input.age > 30`
- Регрессия: S04

### BUG-03
- R-ID: R09
- Заголовок: Неверный порядок распределения бюджета (pump перед vent)
- Шаги: S07/1 (budget=3, два запроса)
- Ожидание: pump=false, vent=true, used=3
- Факт: pump=true, vent=false, used=2
- Серьёзность: высокая (приоритетное устройство не включается)
- Причина: `order: () => ['pump','vent']`
- Исправление: `order: () => ['vent','pump']`
- Регрессия: S07, S01

## 6. Изменение 2.1 и свойства

См. change-impact.txt и delta-tests.json.

Свойства:
1. Инвариант ресурса: used = 2*pump + 3*vent; used <= budget.
2. Инвариант безопасности: fault=true ⇒ pump=false, vent=false, used=0.
